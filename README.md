# vectors-drawing

*Рабочее название открыто.*

Инструмент для тех, кто выбирает форму, а не генерирует её.

Конвейер осмысленной векторной генерации: нормализованное ТЗ → промпт с жёсткими ограничениями → генерация (локальная модель или облако, один OpenAI-совместимый контракт) → headless-рендер → петля критики с жёстким капом → валидация производственной топологии: лазерная резка, one-line, иконография. Валидатор работает и сам по себе — как pre-flight любого SVG перед резкой или линтер в CI.

**Статус:** стадия проектирования. Кода пока нет — есть фундамент:

- [`ARCHITECTURE.md`](ARCHITECTURE.md) — архитектура: библиотека-ядро на Rust, поверхности CLI и MCP, слой валидации как центр проекта
- [`ROADMAP.md`](ROADMAP.md) — фазы от живого раунда руками до публикации
- [`docs/adr/`](docs/adr/) — ключевые решения с альтернативами и последствиями

**Лицензия: не выбрана.** Репозиторий публичный, файла `LICENSE` в нём нет —
значит по умолчанию действует «все права защищены», и переиспользовать
содержимое нельзя. Это временное состояние, а не позиция проекта: выбор между
Apache-2.0 и MIT — открытый вопрос ([`ARCHITECTURE.md`](ARCHITECTURE.md) §13),
отнесённый к Фазе 5 ([`ROADMAP.md`](ROADMAP.md)). Пока решения нет, молчание
README вводило бы в заблуждение сильнее, чем прямая пометка: кода в репозитории
всё равно ещё нет, так что практических последствий у неопределённости немного.
